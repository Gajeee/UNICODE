Good to know




Use UTF-8 firstAdd <meta charset="utf-8"> and you can type most symbols directly. Entities are for reserved characters and invisible ones.


Non-breaking space&nbsp; (160) keeps two words together on one line. Don’t use it for layout; use CSS.


Invisible charactersZero-width space (8203) breaks long strings without showing anything. Zero-width joiner (8205) glues emoji together.


Codes 128–159These are old C1 control codes. Windows-1252 reused them for “smart quotes”, but in HTML5 use the real Unicode codes instead (8216–8221).


Control characters0–31 are non-printing: tab is 9, line feed 10, carriage return 13, escape 27. Shown as ^A…^_ in terminals.


CSS & JS escapesIn CSS content use "\00A9". In JavaScript use "\u00A9" or "\u{1F600}" for codes above FFFF.
